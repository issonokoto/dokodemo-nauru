# どこでもナウル

ナウル共和国の**実寸シルエット**を地図上に重ねて、大きさの感覚を体感するWebアプリです。  
正式版 v1.0.0 です。

**公開ページ:** [https://issonokoto.github.io/dokodemo-nauru/](https://issonokoto.github.io/dokodemo-nauru/)

地図を動かすと、画面中央にナウル（またはナウルくん）がついてきます。赤道付近では小さく、高緯度ではメルカトル図法の影響で大きく見えます。

## できること

- 国の境界 / ナウルくん の切り替え
- 色・回転・反転
- 比較スポット（東京・大阪・博多など）と緯度経度ジャンプ
- 高解像度タイルを使う「高精細（英字・文字くっきり）」地図
- 地図内の文字サイズを標準・大きい（2倍）・特大（4倍）の3段階で切り替え（端末に保存、共有URLにも反映）
- 現在または1995年時点の自治体、国・地域199件、島338件、湖・池253件、観光地・大規模施設1,186件を検索して、ナウルと面積・輪郭を比較
- 「条件から探す」で、全登録データを対象に種類（複数選択）、都道府県・市区町村、面積範囲を組み合わせ、最後に通常の検索欄へ反映
- 通常検索は名称・地域・明示的な所属タグを検索し、種類名からの意図しない自動一致は行わない。種類・場所・面積は条件検索または `種類:` `場所:` `面積:` で指定
- マイ地点（最大2件）
- スクリーンショット保存と X / Instagram / LINE への共有導線

## 面積クイズ（新ルール）

市区町村・島・湖や池がナウルより大きいか、小さいか、ほぼ同じかを答えます。問題数の上限はなく、合計3回間違えるまで続きます。1問12秒で、時間切れも1ミスです。正解は1,000点に速さボーナス最大200点を加算します。10問正解ごとに演出が入ります。難易度は最初からランダムで、正解数に応じた調整は行いません。「大きい」45%・「小さい」45%・「ほぼ同じ」10%を目安に答えの偏りだけを補正し、選んだ答えの未出題候補から等確率で選びます。候補を一巡するまで同じ問題は出しません。選んだ答えの候補を使い切った場合は、残りの全候補から出します。

ランキングは得点と正解数を表示し、得点順・同点なら正解数順です。日間・週間・累計の期間は引き続き利用できます。端末の旧自己ベストは新ルールの初回起動時にリセットします。通信できない場合もクイズは継続できますが、そのプレイはランキング対象外です。

サーバー移行は `supabase/quiz-survival-v2.sql` をSupabaseのSQL Editorで実行します。新ルール用のテーブルとRPCを作成し、旧ランキング・旧ゲームセッションを初回だけ削除します。再実行しても新ランキングは消えません。既存の `quiz-ranking.sql` が適用済みであることが前提です。問題データを更新した際は `node scripts/generate-quiz-survival.js` でSQLを再生成します。公開版へ切り替える前にサーバー移行を完了してください。

survival-v2を導入済みの環境では、`supabase/migrations/20261009164056_quiz_survival_random_questions.sql` を実行すると出題処理だけを更新できます。ランキング・ゲームセッション・回答履歴はそのまま残ります。

## 写真で遊ぶ

地図のメニューから「📸 写真で遊ぶ」を開き、「カメラで撮る」または「画像を開く」を選びます。PC・スマートフォンとも「面積クイズ」と同じ階層に配置しています。画面を開くだけではカメラは起動しません。

スマートフォン・タブレットではプレビューを広く表示し、下の「素材」「文字」「配置・ロゴ」から必要な操作だけを開きます。操作パネルは下から開き、閉じるボタン・同じツールボタン・パネル外のタップ・見出し部分の下スワイプで閉じられます。素材や文字を追加したら自動で閉じ、プレビューで位置を調整できます。パネルを開閉してもプレビューの大きさや配置は変わりません。PCの広い画面では操作欄を右側に表示します。

`camera/` でカメラ映像にキャラクターとロゴを合成して撮影できます。アウトカメラ／インカメラ切り替え、キャラクター選択、移動・ピンチによる拡大縮小と回転、左右反転、撮影後のJPEG保存と対応ブラウザでのファイル共有に対応します。ロゴは初期状態で表示し、独立して移動・サイズ調整・回転・非表示にできます。

ナウルくん、おんライオン、ナウルちゃん、偽リン鉱石くん、リン鉱石くんの5キャラクターを収録しています。歩行型ナウルくんと3Dモデルは保留です。

縦向き・横向きとも、キャラクター一覧と撮影・編集ボタンが1画面に収まります。一覧のタップで最大3体まで追加でき、同じキャラクターも複数配置できます。配置済みの枠または画像をタップして編集する1体を選び、指1本で移動、2本で拡大縮小・回転します。左右反転・削除はボタンで操作します。ロゴは3体の上限とは別枠です。PCでは矢印キーで移動、ホイールで拡大縮小、Shift＋ホイールで回転できます。

カメラは利用者の操作後に許可を求め、映像・写真はサーバーへ送信しません。HTTPSまたはlocalhostで開いてください。USB接続Androidのローカルテストでは `adb reverse tcp:8765 tcp:8765` でPCのローカルサーバーに接続します。iPhoneのSafariは実機確認が必要です。

「画像を開く」から端末内の写真・画像を背景に選び、同じ操作でロゴやキャラクターを貼り付けられます。「＋画像」から手持ちの画像も追加できます。キャラクターと追加画像を合わせて最大3枚、ロゴは別枠です。背景は縦横比を保って全体を表示し、元画像を変更せず、完成した画像を別ファイルとして保存します。JPEGの背景はJPEG、それ以外は透過を保てるPNGで出力します。画像編集の出力は長辺4096pxまでで、それ以下の背景は元の画素数を維持します。選んだ画像も端末内で処理します。

最初の5キャラクターを1枚でも配置している場合だけ、写真・画像の右下に「© ナウル共和国政府観光局」を必ず入れます。都道府県・市区町村・ナウル共和国の図形や手持ち画像だけの場合は入れません。白文字と薄い黒縁の固定表記は、移動・拡大縮小・回転・非表示にできません。ロゴやキャラクターの編集とは独立し、保存画像にも必ず合成します。

「＋ 図形」から47都道府県・全国の市区町村・ナウル共和国の図形を選べます。都道府県で絞り、名前や読みで検索できます。境界と投影は地図の比較機能に合わせています。キャラクター・図形・手持ち画像を合わせて最大3枚です。

「＋文字」から文字を追加できます。画像3枚とは別に最大3つ、各120文字・横書き6行／縦書き6列まで配置でき、配置後も「文字を編集」から内容と文字効果を変更できます。横書き・縦書き、ゴシック・明朝・丸ゴシック・手書き風の4フォント、文字色、標準・影・浮き出し・ネオン・ラベル・グラデーションの6種類、縁取りの有無と色を選べます。文字も移動・拡大縮小・回転・左右反転・削除ができます。文字だけを使っても観光局の©は入りません。追加フォントは選択時に読み込みます。使用フォントの出典とライセンスは `camera/fonts/README.md` と各OFL.txtを参照してください。

## 注意

本サイトはスケール感を体験するシミュレーターです。現在の市区町村・都道府県と、島・湖／池の大部分の面積には国土地理院の公表値を使用しています。1995年時点の自治体と公表値を紐づけられない一部の島・湖／池は、境界データから算出した概算です。島は国土地理院の1km²以上一覧を基準にし、竹島と北方四島のほか、日本最南端の沖ノ鳥島、琵琶湖の沖島・竹生島・多景島・沖の白石、ポートアイランド・六甲アイランド・神戸空港島・出島（長崎）など、面積によらず地理・歴史・文化上重要な島や人工島も追加収録しています。湖・池はWikipedia「日本の湖沼一覧」に掲載された各都道府県の湖沼を中心に、輪郭を取得できたものを収録しています。係争地域は日本政府の呼称・区分に基づき、現在の実効支配についても比較画面に明記しています。シルエットの見た目やメルカトル図法上の表示は、厳密な測量には使用できません。

島・湖／池の輪郭は対象ごとの高精細データに分割し、検索時には一覧だけ、移動・比較時には選択した1件だけを読み込みます。

海外の島は94件を収録しています。ハワイ主要8島、北マリアナ諸島14島、フィリピン・インドネシア周辺の主要島に加え、グリーンランド、グレートブリテン島、マダガスカル島、樺太、台湾島、キューバ島、イスパニョーラ島、ジャマイカ島などの大きく重要な島と、イースター島、マルタ島、マンハッタン島、アルカトラズ島など面積によらず著名な島も検索できます。同名の硫黄島は東京都と鹿児島県を分けて検索できます。

海外の湖・池は26件を収録しています。カスピ海、五大湖、ビクトリア湖、バイカル湖などの世界最大級の湖に加え、死海、レマン湖、コモ湖、ネス湖、ブレッド湖、ウォールデン池など、観光・歴史・文化面で広く知られた水域も収録しています。

観光地・施設は、OpenStreetMapで日本国内の `tourism=theme_park` として登録され、面積比較に使える境界を持つ遊園地・テーマパーク275件を収録しています。過去に日本で開催された国際博覧会5件の会場跡・記念公園、2025年大阪・関西万博会場、大屋根リングも検索できます。点だけで境界を持たない施設は面積を捏造せず、`scripts/japan-theme-parks-report.json` に未解決一覧として残しています。

全国の公園・動植物施設は、境界を持つ大型都市公園・広域公園772件、動物園91件、植物園・植物公園74件、総合動植物公園4件を収録しています。公園は原則0.5 km²以上とし、0.1 km²以上でWikidata・Wikipedia識別子を持つ公園、国営公園、著名な公園を例外として収録しています。選定結果と除外理由は `scripts/japan-parks-zoos-gardens-report.json` に記録しています。

国内の主要スポーツ施設は65件を収録しています。NPB 12球団の本拠地、ほっともっとフィールド神戸など地方開催・準本拠地級の著名球場、Jリーグのオリジナル10に関係する主要会場と日本代表戦級スタジアム、花園・秩父宮・熊谷のラグビー場、花園中央公園・熊谷スポーツ文化公園、日本武道館・国立代々木競技場第一体育館などの大規模アリーナを検索できます。

日本語話者には印象的な響きになる海外地名のうち、エロマンガ島、クサイ島、チンコティーグ島は島カテゴリに、残る8件は観光地・施設カテゴリに追加しました。漫湖は湖・池カテゴリに収録済みです。面境界を持たないボイン川はOSM中心線から片側25m、パンティ山は山頂から半径1kmを暫定比較範囲として明記し、正式な敷地境界と誤認しない表示にしています。

城郭・大規模景勝地は、現存12天守、再建天守系21城、境界面積10ha以上の大規模城跡7城、皇居・京都御所、九十九里浜・鳥取砂丘などの大規模景勝地7件、境界取得できた国立公園12件を収録しています。松山城は松山市堀之内・丸之内、丸亀城は丸亀市一番丁、備中松山城は史跡区域の境界を使用しています。

史跡・古墳は、比較画面で輪郭を見比べられるよう、誉田御廟山古墳、箸墓古墳、五色塚古墳、西殿塚古墳、渋谷向山古墳、津堂城山古墳の前方後円墳6件を個別の閉じた境界として収録しています。大仙古墳は、OSMに記録された墳丘と内濠・外濠を重ね、墳丘を橙色、濠を水色で表示する専用のレイヤー付き輪郭として収録しています。

大規模施設は、空港・飛行場127件、基地・駐屯地・演習場347件、世界遺産の代表名・構成区域83件、港湾・埠頭29件、工業地帯・大規模工場87件、大規模農場・牧場43件、鉱山・採石場53件を個別カテゴリで検索できます。嘉手納飛行場、岩手山演習場、東千歳演習場など、ナウル21km²に近い対象も含まれます。基地は日本国内でOpenStreetMapに名称付き面境界がある区域を面積によらず収録し、点情報だけの施設や境界のない施設は含めていません。

Service Workerは画面とカタログをネットワーク優先で取得し、成功した最新版だけを安定したキーでオフライン予備へ保存します。巨大カタログをインストール時に一括取得しないため、一部ファイルの失敗で更新全体が止まらない構成です。

国・地域は台湾、北朝鮮、パレスチナ、コソボ、クック諸島、ニウエを含む199件を収録しています。国境表現は Natural Earth の日本向け表示を基準とし、極小国・小島嶼国と台湾は geoBoundaries の高精細輪郭を使用しています。

共有ボタンは、ブラウザの制限により画像の自動添付はできません。保存 → クリップボードへコピー → 投稿画面で貼り付け、の流れになります。
