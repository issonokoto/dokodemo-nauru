# 日本語フォント

画面内の選択用日本語フォントを同梱しています。各ファイルは以下の公式配布元から取得し、WOFF2へ変換しました。変換版の内部名は NauruRounded / NauruMincho / NauruHand に変更しています。各フォントの著作権表示と SIL Open Font License 1.1 は同じフォルダーの *-OFL.txt に保存しています。

- 丸ゴシック: [Zen Maru Gothic Medium](https://github.com/google/fonts/tree/main/ofl/zenmarugothic)
- 明朝: [Shippori Mincho Regular](https://github.com/google/fonts/tree/main/ofl/shipporimincho)
- 手書き風: [Klee One SemiBold](https://github.com/google/fonts/tree/main/ofl/kleeone)

追加フォントは選択時に読み込み、写真や文字の内容を外部サービスへ送信しません。標準のゴシックは端末のシステムフォントを使います。
